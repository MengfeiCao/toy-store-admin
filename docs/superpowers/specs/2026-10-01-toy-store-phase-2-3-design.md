# 玩具店后台 2.3 报表与门店效率设计

## 目标

补齐经营报表、Excel 导出、扫码快速开单和 80mm 小票打印，并完成旧页面 Ant Design 交互统一。

## 决策

- 报表由一个受保护的 `get_business_report` RPC 按日期范围计算，返回汇总、每日趋势、商品、库存、采购和售后数据。图表、表格与 Excel 只消费该结果，不重复计算。
- 店主结果包含成本与毛利润；店员结果不包含这些字段，权限在数据库层控制。
- 退款按售后完成日期冲减净销售额；成本按“原出库成本 + 换货发出成本 - 完好退回成本”计算。
- 扫码使用条码精确查询 RPC。扫码页复用 `save_sales_order`，重复扫码只增加同一明细数量。
- 小票读取销售订单快照，独立提供 80mm 打印样式；浏览器打印失败不会修改订单。
- Excel 使用 SheetJS 在浏览器从当前报表结果生成，文件不经过服务端。

## 成功标准

- 日报、月报、商品排行、库存、采购和售后分析可按日期筛选，ECharts 与表格数字一致。
- 30 天无销售且库存大于零的商品进入滞销列表。
- Excel 导出使用相同日期、权限和数据。
- USB 扫码枪回车后精确找货，重复扫描累计，缺货或无匹配明确提示。
- 已完成订单可打印和重新打印 80mm 小票。
- 登录、客户、销售订单等旧表单控件统一为 Ant Design，行为不退化。

## 验证

pgTAP 覆盖退款跨日/月、成本口径、店员字段隔离、滞销和条码查询；Vitest 覆盖报表映射/导出、扫码累计和小票；Playwright 覆盖扫码下单与打印入口。
