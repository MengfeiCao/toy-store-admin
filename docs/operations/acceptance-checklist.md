# 验收清单

## 固定业务案例

- [x] 商品：验收玩具，成本 60，售价 100。
- [x] 采购 10 件并分两次到货后库存为 10。
- [x] 直接确认销售 3 件，订单金额为 300，状态为待出库。
- [x] 出库后库存为 7，成本快照为 180，库存流水为 -3。
- [x] 标记收款后状态为已收款，经营首页销售额增加 300、成本增加 180、毛利润增加 120。
- [x] 修改商品售价为 120 后，历史订单金额仍为 300。

## 权限与异常

- [x] 店员看不到成本、毛利润、用户管理、停用商品和撤销收款。
- [x] 重复到货请求、重复出库、重复采购付款不会重复变更库存或状态。
- [x] 库存不足时整单出库失败，订单保持待出库并允许重试或取消。
- [x] 出库超时后回查订单状态再决定是否允许重试。
- [x] 登录失效会回到登录页；商品图片上传失败可重试。
- [x] 过期盘点被拒绝；重新盘点后可确认差异并生成流水。
- [x] 店员可使用采购与库存，但商品列表、库存列表和经营首页不泄露成本或利润。

## 售后验收

- [x] 已出库订单可按商品和数量部分退货，累计退换不超过原数量。
- [x] 完好退货恢复库存，损坏退货不进入可售库存。
- [x] 已付款退货按原售价退款且原订单保持已收款，未付款订单按净额收款。
- [x] 同款同数量换货原子完成；损坏退回时库存不足不会产生部分修改。
- [x] 售后请求重放不会重复修改库存或生成退款。

## 报表与门店效率验收

- [x] 日报、月报、商品、库存、采购和售后分析使用同一日期范围与统计结果。
- [x] 多商品退款在每日趋势中只统计一次，退款按售后完成日期冲减销售额。
- [x] 店主可见净成本和毛利润，店员响应中不包含这些字段。
- [x] 30 天无销售且仍有库存的商品进入滞销清单，当前报表可导出为多工作表 Excel。
- [x] 条码精确匹配启用商品，重复快速扫描累计数量，未知条码和库存不足有明确提示。
- [x] 快速开单复用销售订单保存与确认流程，已完成订单可打印或重新打印 80mm 小票。
