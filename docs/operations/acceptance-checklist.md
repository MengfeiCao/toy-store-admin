# 验收清单

## 固定业务案例

- [ ] 商品：恐龙积木，成本 60，售价 100。
- [ ] 确认入库 10 件后库存为 10。
- [ ] 直接确认销售 3 件，订单金额为 300，状态为待出库。
- [ ] 出库后库存为 7，成本快照为 180，库存流水为 -3。
- [ ] 标记收款后状态为已收款，经营首页销售额 300、成本 180、毛利润 120。
- [ ] 修改商品售价为 120 后，历史订单金额仍为 300。

## 权限与异常

- [ ] 店员看不到成本、毛利润、用户管理、停用商品和撤销收款。
- [ ] 重复确认入库、重复出库、重复收款不会重复变更库存或状态。
- [ ] 库存不足时整单出库失败，订单和库存保持原状。
- [ ] 出库超时后回查订单状态再决定是否允许重试。
- [ ] 登录失效会回到登录页；商品图片上传失败可重试。

## 交付配置

- [ ] Supabase 迁移、RLS、Edge Function 和 Storage 已部署。
- [ ] Vercel 环境变量只包含公开前端配置，服务端密钥未进入构建产物。
- [ ] 数据库备份、认证回调和 SPA 路由回退已验证。
- [ ] `npm test -- --run`、`npm run test:e2e`、`npm run build` 已执行并记录结果。
